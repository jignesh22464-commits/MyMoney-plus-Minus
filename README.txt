# MyMoney+ Offline — Step 1

This is the first working prototype for the iPhone personal money manager.

Included now:
- Income
- Expense
- Payment/Due
- Automatic remaining amount
- Date
- One-time / monthly / yearly
- Local offline storage in the browser
- Installable as a PWA after it is hosted over HTTPS

Important:
For iPhone installation, this project must later be put on a secure HTTPS web address. The next steps can add Calendar, recurring dues/reminders, savings goals, reports, backup/restore and Face ID-style app security.
