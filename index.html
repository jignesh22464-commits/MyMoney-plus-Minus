Backup Your Data

Save Income, Expenses, Investments, Savings Goals and app data in one backup file.

Transfer Data Between Safari & Home Screen

Safari and the iPhone Home Screen app can use separate local storage. Use a backup file to transfer your MyMoney+ data safely.

  1. In the app where your data is visible, tap Backup → Backup Data.
  2. Save the JSON file in the Files app.
  3. Open MyMoney+ from the Home Screen.
  4. Tap Backup → Choose File and select that JSON backup.
  5. Confirm Restore. The app reloads with your data.

Restore Your Data

Choose a MyMoney+ backup file to restore your data.

⚠️ Restore replaces the current MyMoney+ data on this device.
